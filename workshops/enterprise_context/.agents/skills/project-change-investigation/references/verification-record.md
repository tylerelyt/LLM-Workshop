# 一次变更的验证记录

## 本次运行

写明使用的需求、代码版本与资料版本，列出实际执行的命令及结果。协议连通、模型调用和业务完成分别记录：发现工具不等于模型调用过，工具成功也不等于新增业务已经实现。

## 新增能力

说明输入、观察到的输出或状态，以及它对应哪条要求。文档变化类任务保留事件与原文档的关联；需要恢复或续查时，记录所使用的位置或版本。

## 存量行为与修改范围

检查受影响的旧调用和约定，并核对真实代码差异。没有变化的文件可以用哈希或 diff 佐证；有意改变的行为说明采用依据。

## 结果与下一步

区分已经完成、发现的问题和没有运行的项目。让下一位同事能够复查，不用“全部测试通过”掩盖实际只跑过一条路径。
