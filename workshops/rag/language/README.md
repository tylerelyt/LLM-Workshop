# Workshop · 让中文问题找得到英文原文

发布值班同事问：“生产蓝绿发布已经切流，新版本健康检查失败时，什么情况下允许回滚到旧版本？”知识库里有中文切流检查表、中文演练记录，也有英文生产发布手册。检索只找回前两份，看起来句句相关，却少了决定能否回滚的条件。另一位同事用英文问通知重放，关键的去重规则又只写在中文手册里。

你的任务是把中文和英文片段分开建立索引。提问时，把问题适配到目标库的语种后再投影检索。检索结果要保留原文、版本和来源，值班同事可以自己查到规则。用两条跨语种问题和两条同语种问题验证改动。

## 要交的结果

- 同一组问题用三种方式检索。先用原问题从合库取最多两条候选，再用原问题从每个分库各取最多一条，最后加入查询翻译，继续沿用分库与候选名额。
- 记录每个库实际收到的问题和找到的原文片段。对生产回滚与通知重放各写一句能直接用于行动的结论，附上支撑它的片段、版本和来源。
- 自拟一条带否定词或版本要求的跨语种问题。核对翻译有没有保留这个限制，再判断命中片段能否支撑回答。若失败，指出问题出在翻译、召回还是读错了材料的适用条件。

## 怎样核对

看基线时，指出为什么切流前检查表和演练记录都不能回答生产切流后的回滚问题。看改动后，检查中文问题有没有找回英文生产手册，英文问题有没有找回中文重放说明，两个同语种问题的正确片段有没有丢失。分库结果按语种保留，两个库的分数各用于库内排序。

## 运行材料

`python -m workshops.rag language` 使用 Python 3.10+ 标准库，以固定译文离线预演。输出保留三个检索方案的每条候选、实际问题、命中标记和 Recall@2。这里每题只有一个核验片段，因此 Recall@2 也就是该片段出现在候选中的比例。

接入课堂公共 DeepSeek V4 Flash 调用器时，传入 `lab.run(ask=ask)`。调用器签名是 `ask(system: str, user: str) -> str`。参考程序会拿模型实际译文来检索，每个问题只翻译一次。英文手册和中文手册仍按入库时的语种保存。所有 `lab://` 地址均为练习材料标识。

离线索引用字词稀疏向量模拟两套单语投影。它能重放跨语种检索失灵和翻译带来的变化。生产系统换成实际投影模型后，应用本项目的查询和片段重测召回。

从仓库根目录加上 `--live`，即可通过同一个课程运行器调用 DeepSeek Flash。输出用 `--output` 保存。
