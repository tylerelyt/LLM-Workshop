# 跨语言检索

发布值班同事问：“生产蓝绿发布已经切流，新版本健康检查失败时，什么情况下允许回滚到旧版本？”知识库里有中文切流检查表、中文演练记录，也有英文生产发布手册。检索只找回前两份，看起来句句相关，却少了决定能否回滚的条件。另一位同事用英文问通知重放，关键的去重规则又只写在中文手册里。

你的任务是把中文和英文片段分开建立索引。提问时，把问题适配到目标库的语种后再投影检索。检索结果要保留原文、版本和来源，值班同事可以自己查到规则。用两条跨语种问题和两条同语种问题验证改动。

参考起点已提供材料、两套模拟索引和固定译文。运行默认四题，按 `cases` 逐题核对 `adapted_queries`、候选原文和命中结果，而不是只看汇总 Recall@2。保持语料、问题及总候选名额为 2，比较合库、原问题分库与译文分库三个方案。默认回放的 Recall@2 依次为 0.5、0.5、1.0。

做自拟题时，在 `QUERIES` 的第一题加入“已经发生不可逆迁移”的限制，先写一份保留限制的 `replay` 译文并记录结果。第二轮固定该问题和语料，只把译文里的“不可逆迁移”改成“可逆迁移”。即使正确手册仍命中，也要指出译文条件如何改变了用户问题。核对 `cases[0].adapted_queries.en` 与英文原文中的限制条件。这项对照修改 `lab.py` 的教学问题与译文，结束后恢复原样；接在线模型时保持相同问题，改由 `adapt_question` 调用 `ask` 产生译文。所有输出写到本轮指定的 JSON，每次运行重建内存索引。

## 工程任务

生产问题的正确手册使用另一种语言，翻译还可能改变否定条件和操作顺序。

在 [lab.py](lab.py) 中，固定问题、语料与候选预算，只改变一个译文中的否定条件。

分别检查译文忠实度与召回结果，再决定问题出在翻译、检索还是适用条件判断。

## 要交的结果

- 同一组问题用三种方式检索。先用原问题从合库取最多两条候选，再用原问题从每个分库各取最多一条，最后加入查询翻译，继续沿用分库与候选名额。
- 记录每个库实际收到的问题和找到的原文片段。对生产回滚与通知重放各写一句能直接用于行动的结论，附上支撑它的片段、版本和来源。
- 自拟一条带否定词或版本要求的跨语种问题。核对翻译有没有保留这个限制，再判断命中片段能否支撑回答。若失败，指出问题出在翻译、召回还是读错了材料的适用条件。

## 怎样核对

看基线时，指出为什么切流前检查表和演练记录都不能回答生产切流后的回滚问题。看改动后，检查中文问题有没有找回英文生产手册，英文问题有没有找回中文重放说明，两个同语种问题的正确片段有没有丢失。分库结果按语种保留，两个库的分数各用于库内排序。

## 运行材料

`python -m chapter6.cross_language` 使用 Python 3.11 或 3.12 标准库，以固定译文离线预演。输出保留三个检索方案的每条候选、实际问题、命中标记和 Recall@2。这里每题只有一个核验片段，因此 Recall@2 也就是该片段出现在候选中的比例。

接入课堂公共 DeepSeek V4 Flash 调用器时，传入 `lab.run(ask=ask)`。调用器签名是 `ask(system: str, user: str) -> str`。参考程序会拿模型实际译文来检索，每个问题只翻译一次。英文手册和中文手册仍按入库时的语种保存。所有 `lab://` 地址均为练习材料标识。

离线索引用字词稀疏向量模拟两套单语投影。它能重放跨语种检索失灵和翻译带来的变化。生产系统换成实际投影模型后，应用本项目的查询和片段重测召回。

从仓库根目录加上 `--live`，即可通过同一个课程运行器调用 DeepSeek Flash。输出用 `--output` 保存。

## 独立运行条件

离线模式执行本课教学数据；使用 `--live` 时，先按[模型配置](../../README-DEEPSEEK.md)配置服务，并安装公共依赖。用 `--output` 指定独立的结果文件。

```bash
python -m pip install -r chapter6/cross_language/requirements.txt
python -m chapter6.cross_language --output chapter6/cross_language/results/offline.json
```

默认终端聚焦第一题，显示问题、实际译文、候选原文与命中对照；加 `--case all` 查看四题，或用 `--case CASE_ID` 聚焦另一题。所有题目都会运行；指定 `--output` 后仍显示课堂摘要，并将全部题目的完整轨迹写入 JSON 文件。需要在终端查看完整结构时加 `--json`；离线回放、模型调用与协议验证的范围会在输出中区分。

## 在自己的项目中使用

为自己的跨语种问题写出必须保留的条件，检查译文是否改变否定、时态或适用范围。使用同一套参考文档比较原问题与适配问题的召回，再结合[检索与重排](../reranking/README.md)定位语义改写和排序各自的影响。
