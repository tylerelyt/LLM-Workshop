# 模型预训练技术基础

理解模型怎样从数据学习，以及复用预训练表示时，任务适配真正改变了什么。

结合专栏学习监督学习、深度学习、表示学习与迁移学习，再用小型分类任务检查参数、数据和评估的关系。

## 从基线到任务适配

[冻结嵌入与线性分类](frozen_classifier/README.md)提供标注文本、冻结特征、分类头训练和逐条预测。先检查类别分布和多数类基线，再固定特征与数据划分，比较正则化参数；从误分类样本判断改进方向。

完成后应能指出哪些权重发生了变化，解释训练指标和留出结果为什么可能不同，并知道选型时怎样保留独立测试数据。这项实验覆盖冻结表示上的任务适配；预训练网络和指令微调的机制结合专栏学习。

## 用到自己的任务

换成自己能够复核标签的二分类数据，先定义类别和简单基线，再训练分类头。增加样本之前，检查错误是否来自标签、类别重叠或数据覆盖；比较模型之前，固定划分与特征来源。

需要理解生成式模型的任务数据时，继续看[指令与偏好数据](../chapter5/README.md)；需要区分参数更新与运行时输入时，对照[模型服务](../chapter4/README.md)。

## 参考阅读

- [生成式预训练改善语言理解](https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf)：从预训练到任务适配，理解通用表示与下游监督信号怎样分工。
- [ULMFiT：用于文本分类的通用语言模型微调](https://arxiv.org/abs/1801.06146)：阅读分阶段训练与迁移方法，对照分类头实验，区分冻结表示与更新语言模型。
- [NLP 中的参数高效迁移学习](https://arxiv.org/abs/1902.00751)：理解 Adapter 怎样减少需要更新的参数，进一步思考任务适配的存储与训练成本。
