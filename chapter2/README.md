# 大模型产业发展概述

理解技术能力如何进入产品与业务：场景中的问题是什么，谁使用系统，以及怎样判断投入是否产生价值。

阅读[大模型系统实战](https://time.geekbang.org/column/intro/100613101)与[前沿模型实战课](https://time.geekbang.org/column/intro/100828301)中的相关内容。选择一个熟悉的流程，写清当前做法、待解决的问题、可用数据和错误的影响，作为后续实践的任务背景。

带着这个问题选择[系统实践](../README.md#系统实践)。先定义可核对的结果和基本约束，再决定是否需要检索、工具、工作流或 Agent；完成实验后回看方案是否值得使用和维护。
