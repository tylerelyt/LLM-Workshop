# 大模型技术概述

理解基础模型、GenAI、LLM 与大模型的关系，建立从语言生成、工具增强到智能体的技术地图。

阅读[大模型系统实战](https://time.geekbang.org/column/intro/100613101)与[前沿模型实战课](https://time.geekbang.org/column/intro/100828301)中的相关内容。阅读时选一个自己熟悉的应用，分清模型提供了什么能力，以及数据、工具和运行程序补充了什么能力。

进入动手实践时，从[模型服务与 Session](../chapter4/model_service/README.md)观察一次真实请求，再结合[模型的学习机制](../chapter3/README.md)区分参数中的知识与请求中的信息。
